# JSON Toolkit

A collection of free, simple, fast, and private online tools for working with JSON data.

## Features

- **100% Client-Side Processing**: No JSON data is ever sent to a server.
- **Privacy-First**: No tracking, no accounts, no databases.
- **Tools Included**:
  - JSON Formatter
  - JSON Validator
  - JSON Minifier
  - JSON Sorter
  - JSON Tree Viewer
  - JSON to CSV
  - JSON Statistics

## Tech Stack

- Next.js 16
- React
- Tailwind CSS v4
- Lucide Icons

## Getting Started

First, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
